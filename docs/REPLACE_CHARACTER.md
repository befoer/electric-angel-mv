# 换成别的角色

角色出现在画面里有三种形式：**立绘 / 表情包**（`assets/illust/`）、**从视频素材算出来的剪影、分区图、抽帧**（`build/`），以及代码里写的**名字和界面文字**。换角色就是把这三样换掉，再把几处按图量过的坐标重量一遍。每张素材原本是什么样子、用在哪里、用什么提示词生成的，见 [素材Prompt清单.md](素材Prompt清单.md)。

## 1. 立绘和表情包

`assets/illust/manifest.json` 登记"编号 → 文件名"。换图就是放新文件、改这张表；**没登记的编号会画成占位图，不会报错**，所以可以一张张换着看。

| 编号 | 原图 | 用在哪 |
|---|---|---|
| I01 | 全身正面站姿 | 字符画、像素头像的源图；0:16 前后、0:36、1:27 的「你」人形 |
| I02 | 半身 · 闭眼轻唱 | 0:20、2:22 |
| I03 | 半身 · 开口唱歌 | 0:15（显示器里唱歌的她）、0:24（养成界面的照片） |
| I04a/b/c | 眼部特写 · 睁 / 半闭 / 闭 | 1:11 眼睛特写、眨眼 |
| I05 | 伸手向镜头 | 0:29、1:21 |
| I06 | 抱膝蜷坐 | 1:04–1:11 |
| I07 | 漂浮（文件名 I7.png） | 1:37 |
| I08 | 仰望 · 双臂展开 | 2:29–2:34、2:44–2:48（背后长出代码字翅膀） |
| I09 | 正侧面半身 | 1:11、间奏二结尾 |
| I10 | 背影全身 | 1:24（墙前的剪影，尾巴会摆） |
| I11 | 双手捧起 · 掌心朝上 | 0:26 |
| B01–B16 | 同一套画风的各种动作（ComfyUI 批量图） | Q 系列没有时顶替；部分镜头的小图 |
| S00–S10 | Q 版表情包 | 0:56 专家名牌、尾奏聊天 |
| Q01–Q31、QC1–QC7 | 同一句提示词的一批种子 + 一条图生图链（768² 方图，在 `build/illust_q/`） | 2:43 的快切 |
| 封面主图.png | 她趴在对话窗口里（透明底） | 封面（`render/cover.mjs` 直接读） |

宽高比不用和原图一样，镜头里都按真图的比例放（`core/portrait.js` 的 `aspectOf`）。仓库里的大图已经缩到长边 2048 px（引擎画出来用不到更大的），换图时也不用给更大的。

## 2. 按图量过的坐标（换图以后要重量）

这些地方对准的是原图里某个部位，换图后要在**新图**上重量（画一张带网格的放大缩略图量最准）：

| 在哪 | 是什么 |
|---|---|
| `engine/core/portrait.js` 的 `ANCHOR` | I05 的掌心 / 指尖 / 头顶，I08 的两肩中间（翅膀根）/ 脸——归一化到整张图 |
| `engine/shots/l01.js` 的 `BUST26` | I03 的裁切框和嘴 / 头 / 手 / 尾巴的位置（归一化） |
| `engine/shots/v2b.js` 的 `TAIL10` | I10 背影里尾巴那一段的范围和尾巴根（原图像素坐标，原图 1024×1920） |
| `engine/shots/v2a.js` L15 | I04a 的裁切和眼睛中心 |
| `engine/shots/cover.js` | 封面主图里气泡、输入框、脸、眼睛、宝石的位置（原图像素坐标，原图 2048×1152） |

## 3. 视频素材算出来的数据

这些镜头用的是从短视频里算出来的剪影和画面，不换的话这些地方还是原来的角色：

| 数据 | 原视频 | 用在哪 | 怎么重算 |
|---|---|---|---|
| `build/masks/V1–V3.json` | 转身、伸手、旋转（白底） | 间奏二（1:56 起） | `node scripts/video_masks.mjs` |
| `build/masks/V8.json` | 全身待机、鲸尾摆动 | 0:36、1:27 的「你」人形，1:24 尾巴的摆动节奏 | 同上 |
| `build/masks/V9–V10.json`、`build/maps/` | 两段舞蹈 | 间奏二的线稿 / 深度 / 法线 / 分区上色 | `node scripts/video_maps.mjs` |
| `build/frames/V10/` | 同上 | 间奏二结尾的彩色原画 | `node scripts/video_frames.mjs` |
| `build/frames/V11_3/` + `V11_3_track.json` | 她从上面落下、和鼠标指针互动 | 2:35–2:38 | ffmpeg 抽帧 + `scripts/video_track.py`；动作对字的时间表 `A24` 等在 `engine/shots/v3b.js` |

视频的生成提示词也在 [素材Prompt清单.md](素材Prompt清单.md) 里。脚本都是"从白底里洪水填充出人物"，所以视频最好是纯白底、人物不碰画框。

## 4. 名字和界面文字

角色名「鲸鱼娘」「DS娘」、DeepSeek 风格的对话界面、片尾的制作信息都写在镜头代码里，用编辑器全局搜一下就能找到（`engine/shots/`，尾奏的制作信息在 `outro.js` 开头）。配色在 `engine/core/color.js` 的 `PAL`（三段各一套：晴空 / 夜海 / 晨光）。

## 5. 换歌

比换角色难得多：节拍、小节、人声频谱、每个字的起音、镜头切点都是按这一首歌算的。要换歌，得用 `scripts/` 里的脚本重新分析（见 [HOW_IT_WORKS.md](HOW_IT_WORKS.md)「数据从哪来」），再按新歌的结构改 `engine/timeline.js` 的镜头表。
