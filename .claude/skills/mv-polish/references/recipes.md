# 通用写法（按问题查）

都是"只由时刻 t 决定"的写法：不用随机数和系统时间、不读上一帧，任意一帧都能单独重算（逐帧渲染、跳着预览都一样）。伪随机用按编号的哈希。

## 运动曲线

| 要解决的 | 写法 |
| --- | --- |
| 一次推拉中途不能停 | 写**速度**曲线（慢起 → 平滑加速 → 巡航 → 刹停），按小步长积分成一张表，二分解出巡航速度让总量刚好；缩放倍数在对数空间里积分 |
| 先加速后减速、两段在接点速度相等 | u < k：u² / k；之后：k + (1 − k)(1 − ((1 − u)/(1 − k))²)。落定后用 e^(−at)·sin(ωt) 甩一下（从 0 起，不跳） |
| 浮在水上 | 欠阻尼上浮 1 − e^(−at)(cos ωt + (a/ω)·sin ωt)，再叠两个频率的上下晃 + 慢摆 + 一点漂移；每个元素相位错开 |
| 接住上一个镜头的速度再刹住 | s = 1 + A·(1 − e^(−d/τ))，取 A/τ = 剪辑点那一刻的速度，τ ≈ 0.15–0.3 s；剪辑点之前先跟着上一个镜头的运动走 |
| 逐渐加速的循环（放射线、滚动） | 相位 = 走过的路程：速度 v = 1 + a·d 时路程 = d + ½·a·d²（d = 经过的时间），不要写成 t × v(t) |
| 先慢后快的计数（等级、计数器） | 速率 r(d) = r0 + (r1 − r0)·(d/D)²（d < D），累计 P = r0·d + (r1 − r0)·d³ / (3D²)，之后 r1 匀速；整数部分是计数，小数部分是进度条；"刚升级"的弹跳用 since ≈ 小数部分 / 当前速率 |
| 视频时间重映射（视频比这句长） | 锚点表 [成片时刻, 视频时刻]，用单调三次插值（Fritsch–Carlson）：过每个锚点、速度连续、不倒退 |
| 碰撞 | 碰撞那一刻给冲量和角速度，从那一刻起按固定小步长积分重力和一次落地反弹（只依赖 t − t_hit） |
| 人物慢慢随机摇摆 | 慢噪声 noise(t × 0.3) 映射到 ±0.04 rad + 一个很慢的正弦；要在镜头末尾回正就乘 sin(π·u) |
| 弯曲（尾巴、一缕头发、旗） | 把那一段切出来，绕根旋转，角度随离根的距离增大：φ = θ·s^p（p ≈ 1.3–1.5）；根附近一圈完全不动、切口都落在这一圈里，就没有接缝。逐像素反向旋转、双线性取样。θ 可以取一段参考视频里同一部位的实测摆动，两边动作就一致 |
| 带弹性的旋转 / 落位 | 落位后半径 1 + A·e^(−7s)·sin(20s)；旋转用 elastic-out，过冲几下再停 |

## 错峰与出现

| 要解决的 | 写法 |
| --- | --- |
| 一批窗口由内到外一圈圈弹出 | 按切比雪夫距离分圈；每圈的起点 = 这一圈刚进画面的那一刻，外圈至少晚 4 帧；每个窗口绕自己中心 ease-out-back 0 → 1 |
| 点 / 字先在小处出现再飞到大处 | 每个点有起点和终点，二次贝塞尔飞过去（控制点带一点随机的弯），按到中心的距离错开；收回时外圈先走 |
| 旧的东西留下来慢慢淡 | 换成下一项后旧的按 e^(−2Δt) 淡掉，同时最多画最近几个 |
| 随机闪（频率高但不乱） | 每个十六分音符里错开几次事件，hash(步, 次) 挑目标；包络 0.04 s 满 + 0.08 s 落，正拍那次更重；只压在元素上，强度 ≤ 0.3 |
| 字出现时先强调色再回本色 | 前 0.1 s 强调色，0.3 s smooth 回到本色 |

## 转场

| 要解决的 | 写法 |
| --- | --- |
| 一个元素跨过剪辑点 | 转场窗口里背景照常合成（叠化 / 甩镜），最上面单独一层画跨镜头的元素；这段时间两个镜头都不画自己的那份 |
| 同一样东西两边都画 | 元素的位置写成时刻的函数，两个镜头各在自己的人物之前调用它，叠化时两份重合 |
| 形状之间变形 | 两个形状都采样成同样点数的轮廓，按 e 插值；可以同时旋转、填充渐变、加光晕；四角框先连成整框再变 |
| 两个镜头里长得像的窗口 | 两边各给一个函数返回窗口此刻的 { 中心, 宽高, 旋转, 圆角 }；同一扇窗口插值变形，里面按各自的窗口裁切再淡入淡出；前一个镜头只画窗口以外的部分 |
| 形状遮罩从交互点展开、跟着主体走 | 遮罩中心 = 下一个镜头主体此刻在屏幕上的位置（每帧按相机算）；下一个镜头开头相机偏过去让主体在交互点上，切点后用缓入缓出推回中心 |
| 方块边擦除 + 1 px 外轮廓 | 擦除区域先画成蒙版；蒙版四个方向各挪 1 px 叠起来、再挖掉蒙版本身 = 并集的外轮廓（没有内部线） |
| 画面碎成噪点再变成下一个镜头 | 前一个镜头切成方块，每块在随机（略从中间往外）的时刻换成后一个，换之前那一小段被彩色颗粒吃掉、横向抖 |

## 图形与画质

| 要解决的 | 写法 |
| --- | --- |
| 大片渐变没有色带 | 逐像素按浮点算颜色，加 ±1.5 级的三角分布抖动（两个均匀随机数相减）再量化，缓存成静态图（颗粒不动，编码器保得住） |
| 裁切过的图边缘软到看不出线 | 先按内容做椭圆渐隐，再乘一层贴着四条裁切边的羽化：每条边上正好 0，往里按 smootherstep 升到 1 |
| 字在框里垂直居中 | 量墨迹的 ascent / descent，基线放在 (ascent − descent) / 2；或按大写字母高度居中 |
| 真正的挖空（月牙） | 求两圆交点，路径 = 大圆上远离小圆的那段弧 + 小圆落在大圆里的那段弧；填充和描边都用这条路径 |
| 很窄的尖峰波形不抽搐 | 扫描式显示：每一列只在写入头经过时按那一刻取一次样，前面留空隙；尖峰宽度放大到采样跟得上 |
| 3D 阵列看得出结构 | 独立的块 + 块间留缝 + 层沿法线往后排（间距 ≈ 块宽）+ 同位置前后层的角连线 + 远层更淡更虚 |
| 两张图里的人物对齐 | 缩小后按剪影重合度（IoU）搜高度和位置；不同的图对眼睛：眼中点和两眼距离 |
| 抠白底 | 从四条边做洪水填充（只吃和底色相近的像素）；先确认四边没有素材自带的黑边，否则填充起不了步、黑边会被当成主体留下 |
| 圆形头像里的图不留缝 | 图裁到外圈描边的中线（或外沿），让描边盖住图的边 |
