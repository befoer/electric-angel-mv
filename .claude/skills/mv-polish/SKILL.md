# 镜头打磨准则（MV / 动态图形）

粗剪和成片的分界线在这些地方：东西一帧出现一帧消失、转场是通用的淡入淡出、动作只有平移、节奏没对上音乐、细节差一两个像素、画面里有看起来像出错的东西。下面是一位逐帧审片的导演二十多轮意见里反复出现的要求，整理成了通用规则。

项目自己的硬规则（画面怎么生成、字体与版权、节拍冲击上限等）优先于这里。缓动数值、具体镜头卡以 animation-principles、video-shotcraft 这类专门的 skill 为准；这份讲的是**审片时会被指出的地方**。

## 怎么用

- **设计之前**读「一」到「三」：先想清楚每个元素怎么进、怎么出、怎么和下一个镜头接上，再动手。
- **处理一轮意见**：每条意见对到一条原则上，然后**在全片里找同类问题一起改**——审片人默认你会举一反三。
- **意见只描述了现象、没说要什么**（"这里出现了一点 X""这是出错了吗"）：先当成瑕疵查清原因、去掉，明确回答是或不是、为什么；不要往"加强"的方向猜。
- **对方说"还在"**：从对方看的那一版成片里抽那一帧放大看，把这块像素的整条合成链（父级透明度、底色、叠层、混合模式、素材本身）都查一遍，不要只改第一个看到的地方。
- **交付之前**过「六、自查清单」，用总览图和放大裁切核对。
- 实现上的通用写法（连续变速、按路程积分的加速、接住上一个镜头速度的刹车、欠阻尼漂浮、弯曲、并集描边、抖动渐变……）见 `references/recipes.md`。

## 一、动效：每个变化都有过程，而且有物理感

1. **没有一帧的跳变。** 出现、消失、换位、换形都要有看得见的过程。转场里前一个镜头继续动，不停在最后一帧；剪辑点前最后几帧也不要"定格"——画面突然不动，看起来就是卡住了。
2. **时长让人看清。** 一个要被读懂的变化至少 0.4–0.7 s；整套连锁动作（出现 → 强调 → 连线 → 落定）铺到 1 s 以上；开头"慢慢进入"的阶段宁长勿短。太慢同样会被指出。
3. **动作钉在事件上。** 先找音乐或画面里的事件点（拍、字、另一个元素停下的那一刻），再把起点 / 落点钉上去；事件之间别空等。跟在主体后面出来的界面，主体一完整就出（晚约 0.1 s），留够停留时间再退——等到下一个拍点才出，可能出来就得走。
4. **画面比声音早一点，但只早一点。** 视觉处理比听觉快，切在小节线上会显得"画面慢半拍"（歌常从弱起开唱）。镜头切点放在这一句第一个字前约 1 帧；切点之后才展开的形状转场（圆、心形）再往前约 0.2 s，唱出来时已经打开一半；字和图形的出现提前 0.05–0.2 s。提前太多同样别扭。
   - 自动对齐的歌词时间常错 0.1–0.6 s（一个字唱好几拍、整句错一个音）。要卡在某个音上的东西，用人声分轨先**数音**（一个音对一个字 / 假名，个数对上），再取起音；m / n 开头的字起音在鼻音开始处，比元音早 50–80 ms。
   - 审片人确认过的时刻是锚点，数据和锚点冲突时以锚点为准；换一批对时数据后，回头核一遍以前确认过的地方。
5. **一个运动一条连续曲线。** 两段各自缓入缓出的关键帧接在一起，中间速度归零，看起来就是"卡了一下又走"。一次推拉 / 飞行用一条整体速度曲线（慢起 → 加速 → 巡航 → 刹停），落点刹在拍上。"逐渐加速"的循环运动，相位按走过的路程积分，不要写成 t × 速度（速度一变所有元素瞬间跳位）。
6. **物理感，不要纯平移。** 漂浮 = 欠阻尼（冲过头再回落）+ 两个频率叠加的上下晃 + 轻摆 + 一点漂移；撞击 = 冲量 + 角速度 + 重力 + 落地弹一下；旋转和落位带回弹；拨动、翻转有惯性。人物不要完全静止：±2–3°、几秒一个周期的慢噪声摇摆。跟着主体动作走的东西（被震起的窗口、被风吹走的碎片）速度和主体同一个量级，慢半拍就像拖在后面。
7. **成组出现要错峰，而且有方向。** 由内到外一圈圈、按距离、顺着运动方向或阅读方向；顺序要讲得出道理。
8. **视觉重量和细节匹配。** 越抢眼的元素，自己的动画细节越要丰富；实心大色块、平涂大字、细节比背景还少的主体都要警惕。做不到就让它轻一点。
9. **冲击只给元素。** 整画面的推镜泵、震屏、整屏闪全片 ≤ 3 处，闪 ≤ 0.3；拍上的反应放在字、卡片、图标、旋钮上。高潮那一拍也让元素顺着原来的势头走（窗口继续往外撑、海从底下涨上来），不要所有东西同时炸开。一组面板不要整块左右晃（晃眼、晕），动画放进每个框里面（候选在滚、概率条在抖、亮带扫过、数字在跳）。
10. **字的出场有一下强调。** 新出现的字先短暂变成强调色（约 0.1 s）再用 0.3 s 回到本色；背景大字出场时一圈细描边沿轮廓画出来、停一下就淡掉，描边不留下来、也不要粗。
11. **该变的数字真的在变。** 等级、计数、进度要看得见在涨；"越来越快"的先慢后快——开头一格要看清，再加速，按速度积分，不跳。

## 二、转场：带着一个元素跨过剪辑点

**先看这张表**：做转场之前，先在两个镜头里找能用上哪一招，再决定画法。

| 思路                                   | 做法                                                                                                                                                                                                                                                                        |
| -------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **东西走过去、变成下一个镜头里的东西** | 上一个镜头的一个元素飞 / 长 / 变形成下一个镜头的元素：图标 → 头像框，输入框 → 消息气泡，最后一个字 → 下一个窗口，四角框 → 心形                                                                                                                                              |
| **质感也要对上**                       | 带过去的元素先变成下一个元素的材料（线 / 面 / 点 / 字）：下一个镜头是字符拼成的图形，就让描边图形碎成字符粒子落进去                                                                                                                                                         |
| **最后一个动画 = 第一个动画的位置**    | 剪辑点前眼睛看着哪里，剪辑点后第一件事就发生在那附近；必要时把收尾元素挪过去                                                                                                                                                                                                |
| **人物对上：位置、大小、速度、动作**   | 同一个姿势换图：两张剪影配准再短叠化；不同的图：对眼睛（眼中点 + 两眼距离）反算前一个镜头的推镜终点。前一个在加速推近，后一个也从同样的速度起步、再指数刹住。下一个镜头里在动的部位（尾巴、头发、衣摆），上一个镜头里的同一个主体也要动，而且同一个节奏、剪辑点上相位接得上 |
| **交互点就是转场起点**                 | 形状遮罩的中心放在上一个镜头最后的交互点（手、按钮、表盘中心）；下一个镜头的主体先对准那一点，再用相机推回画面中间，遮罩中心一路跟着主体                                                                                                                                    |
| **背景收拢成生长点**                   | 上一个镜头铺满画面的东西（词、点、字）一起被吸向下一个主体"长出来"的那一点，落进去的那一刻主体展开                                                                                                                                                                          |
| **界面呼应主体的动作**                 | 主体有大动作（起跳、落下、伸手）时，周围的界面跟着反应（被震起、掉下去、被推开），方向和下一个镜头的运动一致——而不是淡出                                                                                                                                                    |
| **方向接得上**                         | 转场里的运动方向 = 下一个镜头的运动方向（被风往右吹走 → 下一个镜头从左边摆进来）                                                                                                                                                                                            |
| **分段钉在字上**                       | 长转场拆几段（连成框 → 停住蓄力 → 加速旋转变形），每段起点钉一个字                                                                                                                                                                                                          |
| **同一样东西两边都画**                 | 跨剪辑点的元素由两个镜头各画一份（同一个时间函数），叠化时重合；飞向人物的画在人物后面、走直线                                                                                                                                                                              |

**不要用**：和画面内容无关的通用转场（百叶窗、普通圆形蒙版、旋转、甩镜——看起来"像 PPT"）；同一个转场设计在两个段落各用一次；零点几秒单独闪一张图。

- **几何对得上**：遮罩的圆心落在下一个镜头那个圆上（必要时挪下一个镜头的相机）；变形的起止用两边真实的坐标；两边有长得像的东西（两个窗口）就让同一个东西变过去，不要各画一个再叠化。
- **推镜停在终点**：转场里前一个镜头继续画时不能再往前推，否则对好的位置又错开。人物走过剪辑点时两个镜头都不画她，由叠层按两边各自那一刻的位置插值画一个。
- **不留尾巴**：上一个镜头的东西要么被带走、要么被盖住淡掉，不能等转场结束那一帧才消失。
- **换掉一个对方不讨厌的手法要谨慎**：嫌"用了好几次"时先减次数、只换其中一两次；大改前留好上一版，方便对比着选。
- **快切**：要切就整段快切，开头就快（十六分音符），切换要有含义；素材必须格式一致——同一画幅的本片画面快速回放，或同一句提示词的一批种子图；比例、透明底、画风不一的杂图混在一起切就是一堆东西在跳。收尾用一串一张比一张接近的图（图生图逐步降低重绘幅度），每张停得越来越久，画面自己"稳"下来，界面上同时讲同一件事。
- **转场的边缘也是画面**：擦除前沿用和主体特效一致的方块边；需要轮廓时描并集的外轮廓（不能出现方块之间的内部线）。

## 三、构图和细节：对齐、留白、层级、不遮挡

1. **1–2 px 的错位看得出来。** 接缝、中线、胶囊里的字（按墨迹或字母高度居中，不按 em 框）、标签和框的对齐。画完放大裁切检查。
2. **标签放进框内的固定角**，不压在框线上。
3. **留白**：主体四周约 100 px；卡片不贴画面边；HUD 和内容互不压，内容给 HUD 让位。
4. **字装得下框**，换字体后重新量。
5. **量要在现在用的那个文件上量。** 素材换成最终版后宽高比、裁边、手的位置都会变；量锚点和裁切范围前现画一张带网格的缩略图放大看。手指、尾巴尖贴着原图边缘时裁切框从 0 开始；底边贴画面下沿可以裁，侧边切过手脚不行。
6. **跟着元素走的字要组合排版**：环绕的字 + 细线刻度 + 一个字块，引线连上，整组一起动、一起退场；元素整段轨迹上字块都要在画面里，停留够读。排成圆的字和附近的圆形元素同一个圆心、同一个弧度。
7. **强调跟着数据走**：数值最大的那个最显眼（跟着数值长大、变实、标上读数）。
8. **前后关系**：飞向人物的元素、流过人物的字画在人物后面；字从轮廓外出生，不藏在身后等出场。
9. **层级和纵深**：大小对比要大；3D 阵列层间距和元素同一个量级、元素之间留缝，后面的层才看得见；远近用虚实、浓淡、视差。有深度的背景入场后也保持深度，再加慢噪声的呼吸；密度从中心往外渐疏；元素大小随机（多数小、少数大），远处的也别淡到看不清。
10. **背景活着但不抢**：静止的窗口随节奏随机半透明地闪（频率要够）；空处放淡淡的小字读数；一直挂着不动的几个标签，换成"随机位置冒出来、停一会儿、退掉的同一类东西"。
11. **每个镜头有一个主体，四周有连在主体上的结构化图形。** 字是配角。结构化图形不是随手撒一团 HUD：引线从主体的边或角长出来，讲的是这个镜头的事，进场有过程（引线画出 → 四角张开 → 内容亮起），跟着拍子走。一段做完看总览图：四周是不是只有底色？
12. **空地让主体长过去**：大片空白时把主体放大、挪过去占满，而不是往空地里塞东西。主体（大字、图）出来之前，它要占的那块地方先放它的"预热"（候选、采样中、底稿）；拼好的结果不要又收回去。
13. **头 0.5 s 不空**：每个镜头切进来的头 0.5 s 就要有读得出的主体——先铺满、再一点点跑起来，不从空白开始一个个加。观众会把"空"当成"没画出来"。

## 四、画质：会被当成出错的画面

- **色带**：跨度小、面积大的渐变在 8 位色深里一级一圈，编码以后更明显。逐像素按浮点算、加三角分布抖动再量化，缓存成静态图；核对时先按出片参数编一遍 H.264 再拉高对比度看。
- **裁切线**：裁切过的图做渐隐，裁切线上必须正好 0% 不透明（贴着四条边各乘一层羽化），否则留下一条直线。
- **素材自带的边**：超分、加黑边的视频帧左右常有几像素黑条；抠图、画图之前先裁掉，两侧一条黑竖线一眼就像出错。
- **抽搐**：按屏幕像素等间距去取一个很窄的尖峰，每帧取到的高度不一样。按信号自己的时间网格取样，或做成扫描式（形状不动，写入头走）。
- **叠影**：主图上淡淡叠着前一张 / 后一张，读起来是一张发灰的半透明图。主图不透明，换图的动感用弹一下、扫描线。
- **巧合的线和带**：半透明的粗竖条、贴在别的东西边上的细线、压在框线上的字，都会被当成渲染错误。挪开，或换成有含义的形式（光点沿一条真实的路径跑）。
- **读不出的形状**：一个圆，是太阳、月亮还是出错？让图形一眼可读（弯月 + 星星）。
- **缝和布尔**：圆形头像里的图要裁到外圈描边底下，不能和描边之间留一道缝；相交图形的挖空按交点拼出真实路径，描边描结果形状；对话气泡的矩形和尾巴是同一条路径。
- **一闪就没 / 被挤动**：前一个动画还没演完就被替换——旧的留下来慢慢淡掉；每帧重新排版导致前面的字被挤动——位置在出现时一次定好。
- **进度倒退**：讲"越来越清楚"的元素每一步都要看得见变好，最后一步是干净的成品，不能中途换内容或变回马赛克；进度环 100% 那一帧还在。
- **残块和缺字**：溶解、擦除要覆盖所有格子；字体缺字退回系统字体时字形会突变，字体串要垫后备字体，换字体后对比渲染查覆盖率。

## 五、风格偏好

- **克制**：节拍反应放在元素层；跨镜头的元素、物理感、错峰是主要的动效语言。
- **程序化图形要有真实含义**：路由、注意力、去噪、心跳间期这类"人做起来很复杂、对代码很容易"的密集图形，背后是真实的技术内容；一种手法别撑一整段。
- **每段有主题和进度感**：一句话能说清这段在讲什么、进行到哪；含义要摆在画面上（用观众认得的界面讲"在做什么、谁在做、做到哪了"），只写在方案里没用。
- **借用真实界面就按它真实的因果来**：没执行完不出成品，采样中只能看到糊的预览；参数、日志、文件名要像真会用它的人写的。
- **界面和画面同一个明暗**：深色画面配深色半透明界面；说明界面小、淡、贴边，主体放得开。
- **按原色画**：插画、立绘、画面里的画面（预览、回放）都按原色，不盖调色层、不压暗；"还没算完"用糊来表达，冷暖用周围的界面和光来给。
- **大字**：不要平涂贴纸，也不要深色厚度 / 浮雕投影；用有内部细节的做法（点阵字：点从画面里的东西飞来拼成字、扫描线、随拍涟漪、离开时被吸走或吹散），进场后别僵着。
- **字由代码画**：生图模型写字常错笔画；封面、标题也用片子自己的字体语言，缩略图里读不出就在字下面垫一层白色"贴纸"边。
- **连线要多、信息要密**：一个出口射出几十根直线、不停换落点，比几根规整的说明线有力量。
- **直接给结果**：铺垫到高潮的变化，落点就是成品本身，中间不插一版风格化过渡；转折处让动作自己停在成品的姿势上，别从动态突然跳成静态。
- **特写也要有正在发生的事**，不是一张放大的图。
- **形式和题材搭**：署名、致谢里不用联名、官方这类会引起误会的写法；名字、链接、编号照对方给的原样写。表情包和梗用在梗对得上的地方，不是哪里空就往哪里贴。
- **视频素材**：不裁、不跳剪、不整体快放。比要用的时间长时按动作分段变速——没有动作的静止段可以压到 4 倍，动作段只快 1.3–1.5 倍，锚点对在字上，用单调插值连起来、速度不跳；能重新生成就改提示词，让视频本身按歌的时间做（每个动作落在哪个字上写进提示词），首尾帧可以留空让人物从画外入场。
- **改动的范围**：对方只说"时间太短"就只改时长，别连样式一起换；一轮只要求改一件事就只改一件；对方喜欢的旧版留着，直到他说不用了。

## 六、交付前自查清单

出总览图（每秒一张 + 每个转场几张）逐项看，必要时放大裁切：

1. **进出**：每个元素的出现、消失、换位都有过程吗？转场末帧有没有突然换图、突然消失？剪辑点前最后几帧有没有定格？
2. **时长**：要读的信息停留够吗？连锁动作是不是挤在 0.5 s 里？
3. **时机**：动作钉在音乐或画面的事件上了吗？切点和字比唱出来早一点（不是卡在小节线上，也没早太多）？卡在某个音上的东西用的是实测起音吗？
4. **曲线**：一次运动中途有没有速度归零？逐渐加速的东西是按路程积分的吗？
5. **物理感**：过冲、惯性、余震有吗？人物是不是僵着？跟着主体动作的东西速度和主体是一个量级吗？
6. **转场**：对一遍「二」的总表——有跨镜头的元素吗？交互点是转场起点吗？位置、大小、速度、方向、质感都接上了吗？有没有和内容无关的通用转场、单独闪一下的图？
7. **对齐**：放大看接缝、中线、胶囊里的字、标签和框角。
8. **边距和遮挡**：主体离边约 100 px？HUD 和内容有没有互压？人物有没有挡住重要的字？
9. **字**：缺字退回了吗？字装得下框吗？
10. **画质**：色带、裁切线、素材自带的黑边、抽搐、叠影、残块、巧合的细线、读不出的形状？
11. **节拍冲击**：整画面冲击和闪没有超出上限？
12. **同类问题**：这一轮修的问题，片子里别的地方还有没有？
13. **含义**：不读方案，光看画面能说出这一段在讲什么、进行到哪了吗？同一种手法是不是连着用了好几次？
14. **空白和密度**：每个镜头的头 0.5 s 有主体吗？四周有连在主体上的结构化图形吗？主体出来之前它的位置是不是空着？
15. **素材**：量锚点用的是现在的文件吗？裁切框有没有切到手脚？换过的素材按真图比例放了吗？
16. **原色**：插画和画面里的画面有没有被盖色、发灰、发暗？
17. **可回滚**：每条改动都能单独退回上一版吗？退回以后和改之前逐像素比过、只有预期的地方变了吗？
