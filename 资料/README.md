# 歌词（自己放进来）

歌词文本有版权，仓库里不带。没有歌词文件时引擎照样能跑，画面里歌词的位置每个字显示成 ♪。

想要完整的画面，在这个目录放一个 **`电子天使-歌词.txt`**（UTF-8）：

- 一行日文、一行中文译文，交替排列；空行会被跳过。
- 日文共 32 行，对应 `data/lyrics_timing.json` 里的 L01–L32。引擎只用日文行，每一行去掉空格和括号里的内容以后，**字数必须和那一句的逐字时间一样多**（`chars` 的个数），不一致会报错并指出是哪一句。
- 中文行目前没有用到，但要占位（隔行读取）。

逐字时间是按小缘翻唱版的那一份录音对的，换成别的版本时间会对不上。
